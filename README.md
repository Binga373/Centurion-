# 🏆 Fédération Internationale du Centurion - Site Officiel

Site web officiel de la Fédération Internationale du Centurion (FIC), la discipline sportive née en République Démocratique du Congo.

## 🚀 Déploiement

Ce site est conçu pour être hébergé gratuitement sur **GitHub Pages**.

1.  Créez un dépôt nommé `votre-utilisateur.github.io` (ou poussez ces fichiers dans un dépôt existant).
2.  Activez GitHub Pages dans les paramètres du dépôt (`Settings > Pages`).
3.  Votre site sera disponible à l'adresse `https://votre-utilisateur.github.io`.

## 🛠️ Technologies

- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- JavaScript Vanilla (ES6+)
- Aucun framework ou backend requis

## 📂 Structure du projet

- `index.html` - Page d'accueil
- `sport.html` - Le sport en détail
- `reglement.html` - Règlement officiel
- `federation.html` - La Fédération
- `developpement.html` - Roadmap de développement
- `galerie.html` - Galerie médias
- `contact.html` - Contact
- `css/style.css` - Feuille de styles principale
